# Commercial Analytics MVP

MVP контрольного центра проекта по построению единой коммерческой аналитики АТОМ.

## Цель
Провести проект от инвентаризации источников и владельцев данных до запуска единого сквозного BI-дашборда.

## Definition of Done
Проект считается закрытым только после того, как единый дашборд:
- собирает данные из согласованных источников;
- показывает путь от первого контакта до продажи/оплаты;
- прошел сверку с бизнесом;
- обновляется автоматически;
- принят коммерческим директором как рабочий инструмент.

## Безопасность MVP
- только синтетические и проектные данные;
- не хранить реальные выгрузки ELMA, Альфа-Авто, 1С;
- не хранить ПДн, телефоны, e-mail, договоры, VIN, коммерческие условия;
- не коммитить `.env`, токены и пароли;
- реальный PROD должен работать только в согласованном корпоративном контуре.

## Запуск локально

```bash
python -m http.server 8080
```

Открыть: `http://localhost:8080`

## Структура
- `index.html` - интерфейс
- `styles.css` - стиль АТОМ
- `app.js` - логика MVP
- `data/project.json` - синтетическая структура проекта
- `docs/SECURITY.md` - правила работы с данными
- `docs/ROADMAP.md` - этапы до закрытия проекта
