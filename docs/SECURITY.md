# Правила безопасности MVP

## Разрешено
- синтетические данные;
- названия систем и команд;
- статусы проектных задач;
- обезличенные примеры полей;
- схемы интеграций без секретов и реквизитов доступа.

## Запрещено без согласования ИБ
- персональные данные;
- реальные лиды и клиентские базы;
- телефоны и e-mail;
- VIN, договоры, платежные реквизиты;
- выгрузки ELMA, Альфа-Авто, 1С;
- коммерческие условия, скидки, себестоимость, маржинальность;
- API keys, токены, cookies, пароли;
- внутренние конфигурации инфраструктуры.

## PROD
Реальные данные должны храниться и обрабатываться только в корпоративном контуре, утвержденном ИБ и владельцами данных.
